# Ново строителство – база (TASK-002 / TASK-007)

Приложено в живата база на 10.11.2026 (миграции `nc_task007_part01…part08`).
Живата база е сверена с тези файлове обект по обект (388 записа: функции, колони, ограничения, индекси, тригери, политики, права).

- `nc_001_new_construction.sql` – таблици, пазач, цена, RLS и права по колони, статус, публикуване, публично четене, планове.
- `nc_002_jobs_rpc.sql` – задачи (създаване, изпълнител).
- `nc_003_hardening.sql` – втвърдяване след втората независима проверка (storage, подпис на производните и др.).
- `nc_001_down.sql` – обратен скрипт за всичко по-горе (изпитан: прилагане → връщане → прилагане → връщане).
- `tests/nc_dryrun.test.js` – изолиран тест (Postgres в процеса, без мрежа): `npm i @electric-sql/pglite && node db/nc/tests/nc_dryrun.test.js` → 33/33.

Нищо в `nd_properties` и останалите съществуващи таблици не е променяно.
