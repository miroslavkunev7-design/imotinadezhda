# Ново строителство – база (TASK-002 / TASK-007)

Приложено в живата база на 10.11.2026 (миграции `nc_task007_part01…part08`).
Живата база е сверена с тези файлове обект по обект (388 записа: функции, колони, ограничения, индекси, тригери, политики, права).

- `nc_001_new_construction.sql` – таблици, пазач, цена, RLS и права по колони, статус, публикуване, публично четене, планове.
- `nc_002_jobs_rpc.sql` – задачи (създаване, изпълнител).
- `nc_003_hardening.sql` – втвърдяване след втората независима проверка (storage, подпис на производните и др.).
- `nc_004_import.sql` – импорт на проектен пакет (TASK-006): само 4 функции (`nd_job_claim_id`, `nd_import_job_begin`, `nd_import_job_done`, `nd_import_apply`); таблици, политики и тригери не се променят. В живата база я прилага координаторът (TASK-006 не пипа живата база).
- `nc_004_import_down.sql` – обратен скрипт само за nc_004 (маха 4-те функции; данните остават).
- `nc_001_down.sql` – обратен скрипт за всичко по-горе, вкл. nc_004 (изпитан: прилагане → връщане → прилагане → връщане).
- `tests/nc_dryrun.test.js` – изолиран тест (Postgres в процеса, без мрежа): `npm i @electric-sql/pglite && node db/nc/tests/nc_dryrun.test.js` → 43/43 (PG 17.5 и PG 18.6; `PGLITE=<път до пакета>` за друга версия).

Нищо в `nd_properties` и останалите съществуващи таблици не е променяно.
