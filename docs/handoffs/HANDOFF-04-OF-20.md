## Remaining — ПРОДЪЛЖИ ОТТУК (не почвай задача 8)

User **не е приел** №7. Последни оплаквания (задължително да се оправят преди следваща задача):

1. **Снимки на опциите:** изрязани, мъгливи, грозни → да са **ясни, цели, без мъгла**.
2. **Бутон ипотека/банки в CRM не отваря банките** — трябва да работи в **admin модул клиенти**. (Имаше опит с portal `z-200`; user казва, че все още не работи.)
3. **Клик върху бележки** не трябва да скролва картата надолу.
4. **4-та папка „Започнати сделки“** до папките на градовете:
   - капаро създава именувана клиентска папка;
   - документи в **извлечения / Фишове / Трудов Договор**;
   - имот → **За имота**;
   - банково досие с работник / изпратено / прогрес.

След като user каже **„супер е“ / „окей“ / „ок“** или отбележи квадратчето за №7 → маркирай Готово в `docs/TASKS.md` + `zadachi.canvas.tsx` и **веднага почвай №8**. Не питай „да почна ли“. Дотогава **не почвай №8**.
