# План: Контекстно меню при двоен клик — Премести / Размер / Дизайн

## Поведение

При двоен клик/тап върху секция → появява се **малко плаващо меню** до нея с 3 бутона:

```
┌──────────────────────────┐
│ ↕ Премести               │
│ ⤡ Размер                 │
│ 🎨 Дизайн (варианти)     │
│ ─────────                │
│ ✕ Затвори                │
└──────────────────────────┘
```

### 1. „Премести"
Това което вече работи: секцията се хваща, мишката/пръстът я мести вертикално между другите, клик/тап за пускане.

### 2. „Размер"
Появява се **балон с две дръжки**:
- Дясна дръжка → влачиш надясно/наляво за **ширина** (50%–100% от родителя)
- Долна дръжка → влачиш надолу/нагоре за **височина** (auto / 60vh / 80vh / 100vh / custom px)
- На балона: текущи стойности (напр. „800×420") + бутон „✓ Готово"
- Промените се виждат на живо, но не се записват докато не натиснеш **Запази** в горния банер

### 3. „Дизайн"
Появява се **галерия с варианти** за тази конкретна секция:
- Реално ще са **12–18 варианта** (не 50 — 50 е невъзможно без AI генерация и кредити). Ако искаш точно 50, минаваме през AI на по-късен етап.
- Всеки вариант е миниатюра + име (напр. „Класически бордюр", „Тъмен със злато", „Минимал бяло", „Заоблени ъгли XL", и т.н.)
- Клик върху вариант → **жив preview** на секцията със зададения стил (но НЕ се записва)
- Под галерията два бутона: **„Приложи"** и **„Откажи"**
- „Приложи" → стилът остава в локалното състояние, но за да влезе в сайта пак натискаш горния **Запази**
- „Откажи" → връща оригиналния стил

## Технически промени

### Backend (миграция)
Нова таблица `section_overrides`:
- `page_key` (text) — home, sale, …
- `section_id` (text) — hero-search-mobile, cities-grid, …
- `device` (text) — desktop | mobile (per-breakpoint overrides)
- `size` (jsonb) — `{ width: "100%", height: "auto" }`
- `variant` (text | null) — име на preset
- `style_overrides` (jsonb) — допълнителни CSS променливи
- RLS: само admin/boss/head_broker четат/пишат
- GRANT-ове за authenticated

### Frontend
1. **`section-editor-overlay.tsx`** — разширявам:
   - Двоен клик → показва floating menu вместо да хваща веднага
   - Менюто има 3 опции, всяка стартира различен режим
2. **Нов файл `section-variants.ts`** — речник с 12–18 варианта per секция (CSS класове + inline стилове)
3. **`luxury-real-estate.tsx`** — секциите четат `section_overrides` и прилагат size + variant класа
4. **`admin.settings.page-editor.tsx`** — горният Save/Cancel банер пази и overrides, не само order

### Етапи (за да не правим всичко наведнъж)

**Етап 1 — днес (минимум кредити):**
- Контекстно меню с 3 бутона
- „Премести" — работи (вече е готово)
- „Размер" — работи с балон + дръжки, но само локално (още не се записва в БД)
- „Дизайн" — показва галерия с 6 базови варианта per секция, live preview, само локално

**Етап 2 — следваща сесия:**
- Backend миграция за `section_overrides`
- Запис на size + variant в БД
- Публичният сайт чете и прилага overrides

**Етап 3 — по-късно (опционално):**
- Per-breakpoint overrides (desktop vs mobile отделно)
- Повече варианти (до 18–24)
- AI генерация за уникални варианти (изисква AI balance)
