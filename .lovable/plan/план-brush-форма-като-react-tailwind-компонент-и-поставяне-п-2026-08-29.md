# План: Brush форма като React + Tailwind компонент и поставяне по референция №2

## Какво ще се направи

### 1. Генериране на brush формата (снимка №1)

- Генерирам PNG 1:1 със същата визия, размер и стил като качената форма — бордо мазка с ръбави четкови краища, без промяна на пропорциите (широка хоризонтална мазка, ~1800×850).
- Изрязвам белия фон → прозрачен PNG.
- Качвам като CDN асет (`src/assets/brush-shape.png.asset.json`) и го ползвам чрез import — без тежък бинарник в repo.

### 2. React + Vite + Tailwind компонент

Нов файл `src/components/site/brush-shape.tsx`:

- `<BrushShape />` — чист presentational компонент, стилизиран само с Tailwind класове (без нов CSS файл).
- Props: `variant` („panel" | „badge" | „pill"), `className`, `children`, `tone` („burgundy" | „white").
- Реализация: формата се ползва като `mask-image` върху бордо фон (не като `<img>`), за да може вътре в мазката да се поставя съдържание — лого, текст, бутон — точно както е на референцията.
- Приема и разлива `className`, forward-ва `ref`, съдържанието идва през `children`.

### 3. Поставяне според референтен скрийншот №2

Компонентът се използва на три места в hero-а, 1:1 със референцията:

- **Голям десен панел** — вертикална бордо мазка с накъсани четкови ръбове, залепена вдясно, застъпваща видеото/снимката.
- **Долна хоризонтална мазка** — минаваща по дъното на hero-а и свързваща се с десния панел.
- **Лого бадж горе вляво** — бордо мазка с бялото лого „НЕДВИЖИМИ ИМОТИ • НАДЕЖДА •" вътре.
- **Бяла „Търси" пилюла долу вдясно** — същата форма, но в бял вариант (`tone="white"`) с лупа + текст „Търси".

### 4. Къде се включва

- Използва се в hero-а на градските страници (`src/components/site/shumen-imposed-page.tsx`, react-panel режим), заменяйки текущите `hero-brush-react` / `logo-brush` слоеве, без да се пипа дизайнът на завършените страници.
- Съществуващите маски (`brush-panel-mask.png`, `brush-card-mask.png`) остават — новата форма се добавя, не изтрива нищо.

### 5. Проверка

- Преглед в превюто на desktop и на 375px мобилно — мазките да не отрязват логото и бутона, съотношението да се пази при zoom.

## Технически детайли

- Само frontend: нов компонент + Tailwind класове + един CDN асет. Без промени в базата, сървърни функции или зависимости от Lovable.
- Формата се вгражда като `-webkit-mask-image` / `mask-image` с `mask-size: 100% 100%` и `mask-repeat: no-repeat` върху `div` с бордо (`#8B1A2B` / по-тъмно бордо от снимката) или бял фон.
- Готово за следващите компоненти, които ще подадеш — компонентът е с варианти, за да се преизползва.
